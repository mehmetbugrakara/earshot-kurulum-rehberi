⚙️ Adım Adım Kurulum Rehberi

İşletim sisteminize göre komutları kopyalayıp terminalinizde çalıştırın.

1

FFmpeg Kurulumu

Zorunlu Gereksinim

Earshot'ın MP4, WAV, OGG dosyalarını okuyabilmesi için sisteminizde FFmpeg bulunmalıdır.

winget install Gyan.FFmpeg
2

Earshot'ı Klonlayın ve Sanal Ortam Kurun

Paket çakışmalarını önlemek için bağımsız bir sanal ortama kurun:

Terminal 
git clone https://github.com/Leonxlnx/earshot.git
cd earshot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[mcp,llm]"
earshot doctor
3

Claude Code'a MCP Olarak Bağlama

Önemli Adım

Modellerin bellekte hazır beklemesi ve anında yanıt vermesi için Claude Code'a tek komutla MCP sunucusu olarak ekleyin:

Claude Code CLI Komutu 
claude mcp add earshot --scope user -e EARSHOT_THREADS=3 -- "C:/path/to/earshot/.venv/Scripts/python.exe" -m earshot mcp
⚡ İpucu (Timeout Çözümü): İlk açılışta modeller belleğe alınırken Claude zaman aşımına uğramaması için oturumu $env:MCP_TIMEOUT=60000; claude şeklinde başlatın.

⚡ Videoda Bahsedilen Temel Komutlar

İçerik videosunda vaat ettiğimiz kritik fonksiyonlar ve pratik kullanımları:

📊 Ses Seviyesi ve Standart Ölçümü

LUFS, dBTP ve dinamik aralığı analiz eder, patlamaları ve kısık sesleri raporlar.

earshot measure video_mix.wav
🎯 Akıllı Efekt Arama & Kırpma

İstediğiniz ses tarifine göre klasördeki en iyi dosyayı ve içindeki en temiz saniyeleri bulur.

earshot rank "crisp whoosh transition" ./sfx/ --top 3
earshot find file.ogg "single clean click"
⏱️ Video-Ses Senkron Kontrolü

Görüntü geçişleri ile ses efektlerinin vuruş milisaniyesini ölçüp spektrogram grafiği çıkarır.

earshot timeline video.mp4
earshot sheet video.mp4 -o sync_raporu.png
✨ Kodla Sıfırdan Ses Efekti Üretme

DSP sentezleyicisi ile geçiş efektleri, pop, tık ve vuruşları anında WAV olarak üretir.

earshot kit init --preset calm -o audio/kit.json
earshot kit render audio/kit.json --out audio/kit
